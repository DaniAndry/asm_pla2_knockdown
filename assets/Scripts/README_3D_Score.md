# 📝 Инструкция: 3D Score Popup для UniversalCollisionHandler

## 🎯 Что это?

Система спавна **3D текстовых надписей** ("+100", "+50" и т.д.) в месте уничтожения объектов.
Текст появляется в **3D пространстве** и всегда смотрит на камеру (Billboard эффект).

---

## 📦 Созданные файлы:

1. **UniversalCollisionHandler.ts** - обновлен для работы с 3D префабами
2. **BillboardText.ts** - компонент для Billboard эффекта

---

## 🛠️ Настройка 3D Score Prefab

### Шаг 1: Создайте 3D префаб для текста

1. **Создайте новый Node** в сцене:
   - Правый клик в Hierarchy → Create → Empty Node
   - Назовите: `ScorePopup3D`

2. **Добавьте Label компонент**:
   - Выберите `ScorePopup3D`
   - Add Component → UI → Label
   - Настройте текст: "+100"
   - Font Size: 50-100 (большой размер для видимости в 3D)
   - Color: Яркий цвет (желтый, золотой)

3. **Добавьте BillboardText компонент**:
   - Add Component → Custom Script → BillboardText
   - ✅ Auto Find Camera (включено по умолчанию)

4. **Сохраните как Prefab**:
   - Перетащите `ScorePopup3D` из Hierarchy в папку Assets
   - Удалите из сцены

---

## 🎮 Настройка UniversalCollisionHandler

### Шаг 2: Назначьте префаб и настройки

1. Выберите объект с компонентом **UniversalCollisionHandler**
2. В Inspector найдите секцию параметров:

```
┌─────────────────────────────────────────┐
│ Universal Collision Handler             │
├─────────────────────────────────────────┤
│ Health: 100                             │
│ Damage Threshold: 1                     │
│ ...                                     │
│                                         │
│ ⚙️ Score System:                        │
│ Main Camera: [перетащите Main Camera]  │
│ Score Prefab: [перетащите ScorePopup3D]│
│ Score Parent: [перетащите Scene root]  │
└─────────────────────────────────────────┘
```

### Параметры:

- **Main Camera** - ваша основная камера (для Billboard эффекта)
- **Score Prefab** - ваш 3D префаб `ScorePopup3D`
- **Score Parent** - родительский узел для спавна (обычно корень сцены)
  - Если не указан, префаб добавится к родителю разрушаемого объекта

---

## ✅ Как это работает

### Процесс:

1. **Объект разрушается** → вызывается `destroySelf()`
2. **Спавнится 3D префаб** в мировых координатах (на 1 метр выше объекта)
3. **BillboardText** заставляет текст смотреть на камеру каждый кадр
4. **Анимация** - текст летит вверх на 2 метра за 0.6 секунд
5. **Удаление** - префаб уничтожается после анимации

### Код анимации:
```typescript
tween(scoreNode)
    .by(0.6, { 
        worldPosition: new Vec3(0, 2, 0) // Летит вверх на 2 метра
    }, { easing: 'quadOut' })
    .call(() => scoreNode.destroy())
    .start();
```

## 🎨 Настройка внешнего вида

### Label параметры (в префабе):

- **Font Size**: 50-100 (крупный текст хорошо виден в 3D)
- **Color**: Яркие цвета (желтый, золотой, зеленый)
- **Outline**: Добавьте для лучшей читаемости
- **String**: "+100" (будет заменен динамически)

### Позиция спавна:

В `UniversalCollisionHandler.ts`, строка 161:
```typescript
spawnPos.y += 1; // Поднимаем на 1 метр вверх
```

Измените `1` на другое значение для другой начальной позиции.

### Высота полета:

В строке 178:
```typescript
worldPosition: new Vec3(0, 2, 0) // Летит вверх на 2 метра
```

Измените `2` на другое значение для другой высоты полета.

## 🔧 Дополнительные возможности

### Отключить Billboard эффект

Если не нужен эффект "смотреть на камеру":
- Просто не добавляйте **BillboardText** компонент на префаб

### Разные тексты для разных событий

В `destroySelf()` метод вызывает:
```typescript
this.spawnScorePopup("+100");
```

Измените текст на любой другой: `"+50"`, `"BOOM!"`, `"💥"` и т.д.

### Случайные цвета

Добавьте в `spawnScorePopup()`:
```typescript
const label = scoreNode.getComponent(Label);
if (isValid(label)) {
    label.string = text;
    // Случайный цвет
    const colors = [Color.YELLOW, Color.GREEN, Color.CYAN];
    label.color = colors[Math.floor(Math.random() * colors.length)];
}
```

## 🎯 Преимущества 3D подхода

✅ **Простота** - нет преобразования координат  
✅ **Надежность** - не зависит от настроек Canvas  
✅ **Универсальность** - работает с любыми камерами  
✅ **Масштабирование** - автоматически меньше на расстоянии  
✅ **Перспектива** - естественно вписывается в 3D сцену

## 🐛 Решение проблем

### Текст не виден:
- Проверьте что `Score Parent` установлен
- Проверьте размер шрифта (должен быть большим)
- Проверьте что префаб активен

### Текст не смотрит на камеру:
- Проверьте что добавлен **BillboardText** компонент
- Проверьте что `Main Camera` назначена
- Проверьте что `Auto Find Camera` включен

### Текст спавнится в неправильном месте:
- Измените `spawnPos.y += 1` на другое значение
- Проверьте что объект имеет правильную worldPosition
